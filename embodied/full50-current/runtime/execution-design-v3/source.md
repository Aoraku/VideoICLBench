# 具身 50 题：执行难度与泛化设计

## 实验单位

每题保留 A/B/C 三个私有规则；每条视频只教该规则的局部操作。难度属于题目，不属于规则版本或泛化条件。主实验使用 I；不支持 I 的题使用 R，并分别报告。支持掩码决定消融范围，不强制每题都支持 I。50 题中，37 题支持 R/I/E，5 题支持 I/E，8 题支持 R/E。

- Easy：一次直接应用所学关系或选择方法。
- Medium：多个相关对象/多次操作或双臂协作；是否双臂由真实控制需求决定，不强制两臂凑数。
- Hard：精细接触操作，或有因果依赖的完整长流程。跨平台不是具身 Hard 的必要条件。
- R：使用演示对象、初始关系和执行目标；允许渲染噪声，但不换输入问题。
- I：同一环境和对象语义，给不同批次、输入布局、数量或参照目标。仅更改随机种子、相机噪声不构成 I；每题须有具体改变。
- E：保持配对基准的输入问题、执行目标和私有规则，只改变环境。支持 I 的题以 I 为基准；不支持 I 的题以 R 为基准。可改变工作区外观、背景、照明及不影响规则含义的空间布局，不能换掉用于判断的颜色、形状或局部坐标定义。

E12、E29、E37、E44、E47–E50 支持 R/E：不另造推理目标，只让同一任务在另一环境中完成。E19 的规则是配盖，不是拧紧，允许保留瓶型身份的同类实例 I/E。

环境配对基准记录为 `environment_base`，不是额外实验条件。R/I/E 与 I/E 题报告 I→E 的环境差值；R/E 题报告 R→E 的环境差值，分别统计。Demo 与 A/B/C 规则保持相同，E 仅改变执行环境；real/sim 视频来源另作独立变量。

## 五个完整长流程

以下内容是任务规格，不表示物理仿真已经验收。机器人可以自主选择动作顺序；依赖链用于实现和判分，不作为逐步操作提示。各题 A/B/C 仅替换局部视频方法，公开订单、包装、运输约束相同。

### E01 套餐订单履约

- **模型任务目标**：根据台面订单，为标记的取餐位准备一份套餐并装箱送达。食物组合按视频中的选配方式；订单只指定取餐位和包装，不指定组合。非套餐食物留在备料区，餐盘内物品不得掉出，交付后工作区不留包装垃圾。
- **局部教学**：只看本题现有 A/B/C 的局部规则视频，不演示整条业务流程。
- **执行依赖**：从备料架取得订单指定的空餐盘和餐盒；按视频选择套餐；装入盒内、盖合；把完整盒子送到订单对应取餐位，归还未用配件。
- **因果关系**：订单/餐盒/取餐位形成身份链，最终收件区必须收到包含正确食物的同一个盒子。
- **判分**：选配及稳定装盘35%；正确装盒并盖合25%；同盒正确交付与工作区约束40%。
- **资产**：刚体食物、托盘、带铰链盒、两级备料架、两处标记取餐位。
- **I/E**：I 换订单/批次/输入关系；E 保持配对输入，换台面、工位位置和包装外观。仅支持 IE，因为局部 demo 不包含完整工作流程。

### E09 分类教具配套出库

- **模型任务目标**：为本次课堂准备完整三包教具，分组对应关系按视频。每包有三件且放入独立透明盒，盒内不得混组；将三盒装入订单指定的周转箱并送到对应领取区，备用件留在原架。
- **局部教学**：只看本题现有 A/B/C 的局部规则视频，不演示整条业务流程。
- **执行依赖**：读取公开订单的教具批次和领取区；从料架取九件目标物，按示范分成三组；三组各装一盒并盖合；将三盒放入同一周转箱，再运输交付。
- **因果关系**：批次决定可用物品，分组决定盒内成员，组包关系必须随装箱和运输保留。
- **判分**：三组成员正确35%；每组完整封装25%；全部同批次装箱送到正确领取区40%。
- **资产**：九个形色组合块、干扰批次、三只透明盒及盖、周转箱、领取区。
- **I/E**：I 换订单/批次/输入关系；E 保持配对输入，换台面、工位位置和包装外观。仅支持 IE，因为局部 demo 不包含完整工作流程。

### E17 展示架补货与开场准备

- **模型任务目标**：为指定展台完成一次开场备货。按视频的分层对应关系摆放本批展品；展示架必须在订单指定位置，包装收回回收盒，架上不得混入其他批次展品。
- **局部教学**：只看本题现有 A/B/C 的局部规则视频，不演示整条业务流程。
- **执行依赖**：核对订单展台和批次；取得并摆正展示架；拆取目标展品，按示范分层；将包装回收，最后把装有展品的展示架移到指定展台。
- **因果关系**：先定位展示架及批次，再分层，搬运后仍需保持正确支撑关系；只在操作台分好层不算交付。
- **判分**：正确批次展品全部分层35%；包装回收且上架稳定25%；整架正确到位并保留层位40%。
- **资产**：固定刚体双层架、可移盖包装箱、回收盒、两处展示台。避免柔性包装。
- **I/E**：I 换订单/批次/输入关系；E 保持配对输入，换台面、工位位置和包装外观。仅支持 IE，因为局部 demo 不包含完整工作流程。

### E20 耗材盘补量后封装交付

- **模型任务目标**：把订单指定的耗材盘准备成可直接使用的一套并送往指定工位。各图形区的配色和补齐后的总数量按视频；已有合格耗材计入总数，不得清空重装，备用耗材不应随盘送出。
- **局部教学**：只看本题现有 A/B/C 的局部规则视频，不演示整条业务流程。
- **执行依赖**：从存储位取对应耗材盘，保留盘内已有筹码；依据配色及总数规则补足；盖好固定透明盖，送到对应工位，剩余耗材放回料架。
- **因果关系**：订单选择盘与工位，初始数目决定补多少；计数结果须随封装与搬运保持。
- **判分**：各区正确颜色与总数35%；正确封装且保留原有筹码25%；正确工位交付和余料归位40%。
- **资产**：三色筹码、三图形凹格盘、透明盖、料架、两工位；盘初始每区0至目标数。
- **I/E**：I 换订单/批次/输入关系；E 保持配对输入，换台面、工位位置和包装外观。仅支持 IE，因为局部 demo 不包含完整工作流程。

### E39 参照工装校正与成品交付

- **模型任务目标**：为指定订单校正工装并交付。按视频所示的校正范围处理工作盘，对照上方参照盘；不属于校正范围的属性保持不变。参照盘不能动，合格工作盘装进保护盒后送往订单指定检验位。
- **局部教学**：只看本题现有 A/B/C 的局部规则视频，不演示整条业务流程。
- **执行依赖**：读取订单定位参照/工作盘；只按示范范围纠正颜色次序和/或朝向；将工作盘置入保护盒并盖合；完整送往检验位。
- **因果关系**：参照身份决定正确关系；原始工作盘决定被保留的属性；盒内和终点仍核验相对关系，不允许直接拿参照盘交付。
- **判分**：正确校正且保护属性35%；同一工作盘完整保护装盒25%；正确检验位交付且参照未动40%。
- **资产**：两套T形块及有定位槽的盘、透明保护盒、检验位；不用抓取自由叠放的整套散件。
- **I/E**：I 换订单/批次/输入关系；E 保持配对输入，换台面、工位位置和包装外观。仅支持 IE，因为局部 demo 不包含完整工作流程。

## 仿真实现与验收契约

优先复用 Isaac 中的现成刚体、Articulation 关节和仓储/桌面组件；透明盒、带槽盘、料架可由现成基础几何建模。五题不依赖柔性食品包装、布料或流体。展示架、包装盒和托盘按完整物理刚体运输，不用 teleport、自动吸附或脚本替 agent 送货。若盖合物理尚不稳定，先完成夹具建模与参考控制验收，再进入正式评测。

评分同时保留 strict_success 与 process_score。中间得分点必须对应真实保存的物理状态，不能按执行动作次数给分；搬运时遗失/散乱会使相应状态不成立。非目标重大破坏、错误收件位和取走参照件不能取得完整成功。每个状态需连续稳定若干仿真步，阈值由尺度与接触容差统一确定并写入场景配置。

每个支持条件先做至少 3 个种子 × A/B/C 的正例及错误成员、错误终点、错规则、未释放反例。R/E 题验证同一输入在两种环境下的可达性和同一评分标准；I/E 题不用局部 demo 伪造整任务 R。已有实拍中的不完整或重复规则片须保留质量标记，不补写未实际出现的操作。E05-A 的不完整视频须单独确认，不得默认为完整监督。
