# G2 对象替换检查

已按设计文档生成 E04、E05、E06、E07、E09、E11、E20、E36、E41、E49 共 10 题、56 个对象的推理资产。机械臂与桌面由 G2 独立环境配置提供。现有 demo 文件没有改动。

| 任务 | 实际新对象 |
|---|---|
| E04 | 红苹果、绿梨、蓝色带盖收纳罐 |
| E05 | 带丝带立方礼盒、近球形橙子、三角糕点 |
| E06 | 三颗同外形、同颜色的小柑橘；保留六孔托盘 |
| E07 | 同款、统一缩放的五个闭合套娃外壳 |
| E09 | 红绿蓝糖霜 × 圆方三角外形的九块饼干 |
| E11 | 苹果、橙子、柠檬、梨；保留开局 2×2 布局和四格框 |
| E20 | 红黄蓝三色四孔纽扣，原备件数量与已有件数保留 |
| E36 | 四个等价的小苹果，保留空盒 |
| E41 | 同截面、短中长三档的橡皮条，前段与备件各一套 |
| E49 | 五张真实照片贴面的薄卡；同背面、不同正面，保留彩盘 |

E06 使用设计的“小柑橘”，统一修正表格推理提示误写的“鸡蛋”。E20 是三种颜色、每件四孔。

所有任务的 A/B/C `variants`（包含 goals、semantic、zones 和初态 overrides）与原绑定完全相同；对象 ID、身份、质量、摩擦和接触参数保留。目标标记、托盘、盒子、盘子保持原资产。E11 水果半高由 3 mm 调为 20 mm，保持 20 mm XY 半径和原 bottom，避免生成压扁水果；水果尺寸小于各目标格的 35 mm 半宽。

E49 原尺寸为 88.3054393 × 63 × **0.35 mm**。新卡没有增厚、抓手或凸起；采用不可见的精确薄片碰撞体、可见侧沿与统一背面、位于 +Z 的单独照片面。侧沿网格删除了顶面，照片面不与其他可见面重叠，避免世界坐标浮点精度造成闪烁；总厚度仍为 0.35 mm。五张背面几何和材质一致，原始序号、初始翻面四元数和目标盘关系保留。正面照片来自固定版本 scikit-image 样例资产，下载 URL 和实际 SHA256 已写入 `assets/g2/provenance.json`，纹理依赖也进入各资产的 SHA256 清单。照片内容不用于判分。

碰撞采用闭合刚体凸包。果梗、叶片、糖霜、丝带和外表装饰只用于显示，不添加可抓取把手。纽扣有真实可见的四孔，碰撞采用其外包络；E20 不包含穿孔操作。所有资产仅为本次推理对象，原始资产保持原样。

- 物理可达、接触、翻卡和模型任务成功仍须由原生仿真测试给出。以上 CPU 检查不表示任务已成功执行。

生成入口：`runtime/scripts/build_inference_g2_assets.py`。完整绑定 patch：`g2-bindings-patch.json`。资产已冻结供父任务编译和原生测试。

## UR5 专用腕相机复核

原配置下 TCP 投影在 `(320, 525.16)`，超出 640×480 画面。新专用 profile 根据原生固定链 camera→ee 的相对变换，将腕部光学朝向调整 21.68046°，使 TCP 居中 `(320, 240)`，深度 0.140757 m；近裁剪面改为 0.03 m。FK 证据位于 `ur5-wrist-fk-audit.json`。这项调整只作用于 G2 专用 profile。指尖网格 Z 最远端 0.1305 m，加 guide 固定偏移 0.023 m，验证配置的 ee_link +X 0.1535 m TCP 正确。原生遮挡和运动跟踪仍待 probe。
