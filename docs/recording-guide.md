# 人工教程录制

## 准备

平台需要控制服务和应用 Worker 同时运行。使用任务大厅选择 1–75 题及 A/B/C 版本，运行用途选择“教程演示”，种子选择 0–999。每个教程使用独立运行。

点击“准备独立环境”后，远程画面来自该运行的独立浏览器进程。录制者规则卡位于画面之外；录制开始时，规则字幕会进入视频的前四秒。模型任务画面不包含规则卡。

## 操作

1. 阅读规则卡及任务资料，确认所需对象、阈值、指定词和收件人。
2. 点击“开始录制”，在远程画面中操作鼠标和键盘。点击画面可获得键盘焦点，粘贴用于长文本及中文输入。
3. 完成目标后点击“结束录制”。建议长度约 20 秒，最长 45 秒。停止录制会封存业务输入。
4. 点击“结束并评测”。通过后播放 MP4，检查字幕、指针、操作结果是否清楚。
5. 填写审核人和说明，提交审核。重置会归档该轮视频、状态和事件，并使旧应用凭证失效。

文字编辑题需要完整填写目标内容。群聊任务选择三名联系人后确认邀请。队列题通过上下移动按钮调整顺序，再确认保存。“检查后处理”任务需要先检查再执行保存、复制、发送或提交。编程本地检查为 Python 语法检查；缩进与变量名任务由规则及 AST 判分，提交代码不会在控制服务中执行。

## 判分与证据

发送消息以收件人、正文和附件引用为准；群聊以真实成员关系为准；列表、购物车和收藏以集合变化为准；转账以双边账本、余额变化及守恒为准。复制任务同时校验独立浏览器的实际剪贴板。游戏任务重放操作并核对实际棋盘。

判分后浏览器进程释放，最终截图和视频可继续查看。未通过时应检查具体子目标与过程约束，创建新的演示或重置后重新录制。自动化验收视频不能作为人工教程。

## 数据划分

演示种子为 0–999，开发为 1000–9999，评测预留为 10000 以上。对象标识随实例种子变化，不能把示范中的对象 ID 直接复制为评测答案。任务版本、初始状态、代码构建和来源提交均进入证据。

系统任务 76–100 暂不录制；其执行池与适配器为独立交付项。
