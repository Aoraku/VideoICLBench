# 人工教程录制

## 录制范围

平台通过统一入口打开应用。Chat、IM、Music、Code 和五子棋使用来源仓库的界面技术与组件；News 提供新闻首页、阅读与编辑功能。新增应用拥有各自的首页、导航、列表与详情页面。应用任务 1–75 需要逐题人工验收；系统任务 76–100 暂缓。

## 完整流程

1. 打开平台，在任务列表点击题目，选择 A / B / C。任务卡显示版本规则、操作路径、需要处理的内容和完成要求。
2. 点击“开始录制”。应用在新标签页直接打开默认首页；浏览器需要授权时，选择**应用标签页或所在窗口**。无需选择运行模式、用途或数据参数。
3. 从首页通过应用导航找到目标页面，按任务卡规则完成操作。批量任务需要处理全部 24 个演示对象；显示“练习 1 / 6”的任务需要连续完成六组，每组操作后点击应用右下角“下一组”。保留首页、导航、任务过程与结果，不要只录最后一步。
4. 六组任务在最后一组点击“完成练习”，内置录屏会自动结束、保存并检查；批量任务完成后回到任务卡点击“结束并保存录像”。使用外部录屏时，手动结束并上传视频。任务 43B 还需要粘贴实际复制的内容，再点击检查。
5. 回放视频，确认画面、文字、鼠标和操作结果清晰可辨。展开“审核录像”，填写审核人和说明，确认完整后提交。

需要重录时，在任务卡点击“重置环境”，再点击“开始录制”。重置从首组重新开始，服务端归档本轮操作及录像；需要直接使用的录像应先下载。录制、上传期间不能切换题目或版本，也不能重置。

内置录屏最长 30 分钟，文件上限 150 MB，不包含音频。不支持屏幕录制或未允许共享的浏览器仍可打开应用；此时使用系统录屏，并在任务卡上传 WebM / MP4 文件。上传失败时可下载原始录像并重试保存。页面关闭前需完成保存。

规则卡仅供录制者阅读，不叠加到应用画面中。开始录制后任务卡隐藏规则；确认内置及外部录屏均已停止，再点击“已停止所有录屏，返回任务说明”。选错窗口、遗漏首页或导航、任务操作失败的录像不能审核通过。平台使用固定的教程演示数据，版本 A / B / C 共享同一组初始对象。

## 业务操作

- 联系人分组选择后点击保存；消息颜色标签选择后立即保存并在消息旁显示。
- Music 与视频队列的上下移动会立即保存顺序。
- IM 发起群聊时选择三位联系人，再点击完成。
- 新闻阅读清单需要选好文章后点击保存阅读清单。
- 生成代码先检查，再执行保存、复制或发送；编程提交保存在独立提交记录中。
- 五子棋打开练习棋谱后操作原 SDL 棋盘；其他游戏从游戏大厅打开练习。

## 判分与证据

消息按收件人、正文、引用和附件判分；群聊按成员关系判分；分类、收藏与列表按业务表判分；转账按双边账本及余额守恒判分。Agent 复制任务核对服务器浏览器实际剪贴板；人工任务 43B 需要在工作台粘贴实际复制内容，评测证据注明 `human_paste`。代码题采用文本规则、AST 结构及语法检查；游戏重放实际动作并核对棋盘。

统一接口为 `POST /v1/tasks/{task_id}/eval`。人工评测保存业务状态和事件，录像来源标记为 `human_browser`，首页完整性需要人工确认。远程 Agent 评测另有服务器最终截图和输入事件。

## 复核要求

人工逐题确认正常路径通过、错误规则被拒绝、刷新后业务结果保留、重置后数据恢复。反馈应包含题号、版本、记录编号、操作步骤和截图；记录编号可在任务卡的“问题反馈信息”中查看。自动化验收录像属于工程证据，正式教程需要人工录制与审核。
