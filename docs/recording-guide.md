# 人工教程录制

## 录制范围

平台通过统一入口打开应用。Chat、IM、Music、Code 和五子棋使用来源仓库的界面技术与组件；News 提供新闻首页、阅读与编辑功能。新增应用拥有各自的首页、导航、列表与详情页面。应用任务 1–75 需要逐题人工验收；系统任务 76–100 暂缓。

## 完整流程

1. 在任务大厅选择题目、A/B/C 版本、“独立应用页面（人工试用与录制）”和“教程演示”。演示种子使用 0–999。
2. 点击“准备独立环境”，阅读工作台的规则卡，点击“打开独立应用”，在新标签页的应用工作台停留。
3. 返回控制工作台，点击“开始屏幕录制”，在浏览器的分享窗口中选择**独立应用标签页或窗口**。需要浏览器支持屏幕录制，推荐使用 Chrome 或 Edge；也可以上传本机录屏软件导出的 WebM / MP4。
4. 切回独立应用，点击“打开应用”，展示默认首页，再通过导航进入任务页面。录像应包含入口、首页、导航和完整操作。
5. 按示范规则操作。菜单、输入法、滚动、拖动和快捷键由本机浏览器处理。检查保存结果、消息、分类标签或回执确实更新。
6. 返回控制工作台点击“结束并保存录像”。上传并转码成功后，业务输入封存；点击“结束并评测”。上传失败可下载原始录像保留，并重试保存。
7. 播放 MP4，确认录到了正确窗口，首页、导航、任务过程与结果完整可辨认。填写审核人和说明，确认录像完整并审核通过。

人工录像最长 15 分钟，文件上限 150 MB，不包含音频。工作台不会自动把规则卡叠加到人工录像中；选错窗口、遗漏导航或操作失败的录像不能审核通过。需要重录时点击“重置环境”，关闭旧应用标签页并重新打开。

“远程会话（Agent 执行）”使用服务器截图与键鼠接口，服务器录制默认上限 120 秒，可通过 `VIC_RECORDING_MAX_SECONDS` 配置为 30–180 秒。该入口用于 Agent 与自动化测试。

## 业务操作

- 联系人分组选择后点击保存；消息颜色标签选择后立即保存并在消息旁显示。
- Music 与视频队列的上下移动会立即保存顺序。
- IM 发起群聊时选择三位联系人，再点击完成。
- 新闻阅读清单需要选好文章后点击保存阅读清单。
- 生成代码先检查，再执行保存、复制或发送；编程提交保存在独立提交记录中。
- 五子棋打开练习棋谱后操作原 SDL 棋盘；其他游戏从游戏大厅打开练习。

## 判分与证据

消息按收件人、正文、引用和附件判分；群聊按成员关系判分；分类、收藏与列表按业务表判分；转账按双边账本及余额守恒判分。Agent 复制任务核对服务器浏览器实际剪贴板；人工任务 43B 需要在工作台粘贴实际复制内容，评测证据注明 `human_paste`。代码题采用文本规则、AST 结构及语法检查；游戏重放实际动作并核对棋盘。

统一接口为 `POST /v1/tasks/{task_id}/eval`。人工评测保存业务状态和事件，录像来源标记为 `human_browser`，首页完整性需要人工确认。远程 Agent 评测另有服务器最终截图和输入事件。

## 复核要求

人工逐题确认正常路径通过、错误规则被拒绝、刷新后业务结果保留、重置后数据恢复。反馈应包含题号、版本、种子、run_id、操作步骤和截图。自动化验收录像属于工程证据，正式教程需要人工录制与审核。
