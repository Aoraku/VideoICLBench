# 录制前验收

## 自动化范围

| 检查 | 验收内容 |
|---|---|
| 任务与规则 | 100 题配额、300 个规则契约、75 个已实现任务 |
| 领域业务 | 两个种子上的 75 题 × 3 版本，正确结果和反事实版本拒绝 |
| 真实 GUI | 75 题 × 3 版本，通过应用页面进行编辑、分类、选择、排序、动作和棋盘操作 |
| 像素与录像 | 通过截图和键鼠接口操作真实应用，录制 MP4、封存输入和评测 |
| 并发 | 15 个独立应用会话，含 5 路同时录像；跨运行凭证拒绝及单实例重置隔离 |
| 业务反例 | 错误收件人、账本／余额不一致、无操作、错误规则、越权、幂等冲突、过期 epoch |
| 生命周期 | 重置归档、视频不可跨轮审核、销毁不可恢复、判分幂等及任务编号绑定 |
| 代码与游戏 | AST 结构／绑定、缩进规则、合法移动、停止时机和棋盘重放 |

GUI 验收使用私有 QA 定位器驱动浏览器；模型对外协议保持截图与键鼠输入。所有应用可在同一门户创建并录制；运行结果和最终截图可由接口读取。

## 数据集门槛

自动测试视频仅作为工程验收证据。正式教程需要人工录制与审核；视频内容、任务版本、输入种子、操作轨迹和结果必须一致。系统 25 题需完成独立执行适配后才能录制。

实际验收数字、构建镜像和检查结果见 `docs/verification.json`。CI 工作流包含核心测试、像素录制和全部应用 GUI 验收；流水线触发后的结果以 CI 运行记录为准。
