# 录制前验收

| 层次 | 内容 | 证据 |
|---|---|---|
| 规则与业务 | 100 题契约，软件与游戏的正确状态、反事实拒绝、隔离和重置 | pytest |
| 应用任务路径 | 从入口进入首页，经导航完成任务；分类、保存与刷新后持久化 | `scripts/check_native_ui.py` |
| 远程输入 | 截图、坐标点击、右键、键盘、滚动与录制 | `scripts/smoke_application_pixels.py`、像素分类复测 |
| 原生桌面 | 原 SDL 画面经桌面连接输入，业务状态与判分一致 | Linux 容器五子棋检查 |
| 视觉与真实性 | 首页完整、导航自然、内容可理解、控件可用、任务结果可辨认 | 人工逐题审核 |

`check_application_ui.py` 属于开发诊断控件回归，不作为原应用前端验收证据。自动化录像不作为正式人工教程。系统任务 76–100 暂缓。

正式教程必须从应用入口开始，展示默认首页与导航过程。评测通过还需要视频内容与题目、规则版本、种子一致，最终由录制者和审核者确认。
