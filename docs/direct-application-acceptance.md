# 独立应用入口验收

日期：2026-09-24。执行服务：agentlab。应用代码：`1fa6856`。

## 使用方式

任务大厅提供 13 个应用模块的独立页面入口。录制者在自己的浏览器中使用应用，控制工作台负责准备环境、规则卡、重置、录像与评测。工作台和应用使用不同端口；各次运行的数据与应用凭证独立。

人工操作不受远程 Agent 会话的五分钟、120 次输入和 300 次业务命令限制。远程 Agent 接口保留截图、键鼠和执行预算。五子棋通过独立页面连接原 SDL 应用。

访问步骤及双端口 SSH 命令见 [团队访问说明](agentlab.md)。

## 自动化与录像

全套回归测试 557 项通过。独立应用与录像证据专项 6 项通过，覆盖运行隔离、重置、封存、302 次人工业务操作、录像鉴权与解码、审核门槛、剪贴板证据来源。

浏览器文件选择、上传、转码与页面内播放使用两秒测试片验证。该测试片不属于任务教程，不通过正式录像审核。屏幕共享授权与实时屏幕采集未包含在此次验收中。

内置浏览器原生媒体控件的辅助功能调用出现过标签页崩溃；使用可见播放按钮的坐标点击可完成页面内播放。原生媒体控件的辅助功能兼容性不列为通过项。

## 验收边界

这些记录证明 13 个应用的独立入口与代表性操作链路可用，不等于全部 225 个应用规则版本或所有产品功能均已完成人工验收。正式教程需逐题确认首页、导航、规则、种子、结果与视频内容一致，并由录制者及审核者确认。
