# E43：用导向条让球经过图形区域

这是维护者说明。下表用于核对任务和评分，**不能作为模型的额外规则提示**；模型只获得对应输入组允许的指令、示范及正常观测。私有工程参考、答案、评分历史与检查点不得进入模型观测。

## 目标与 ABC

保持发射架固定，布置并实际握持导向条，操作真实闸门，让球依靠重力释放、碰到导向条后偏折，轨迹穿过指定标记纸区域。

| 变体 | 球轨迹应经过的目标 |
|---|---|
| A | 圆形标记纸 |
| B | 三角形标记纸 |
| C | 方形标记纸 |

当前验收范围为 **I / seed4201 / ABC**。I 改球起点和目标标记布局，需要重新摆放导向条，映射规则不变。

## 物理动作与原生条件

球必须由固定发射架的真实闸门释放。原生轨迹需记录：球起初被保持、随后释放；被实际握持的导向条与球有接触力，并使运动方向发生变化；偏折后的球心轨迹线段与对应纸区相交。全段禁止手指直接碰球，发射架不得被移动。

两项原生条件是 `released_contact_deflected_path_crosses_paper`、`launcher_remained_fixed`。这是经过区域的事件任务，**不要求球最后停在纸上，也不增加末态稳定检查**。模型报告“完成”、视觉上接近纸区或只有导向接触，都不能替代原生轨迹证明。

## 必需开关与配置

在构造场景、计算身份或启动 `build / run / serve` **之前**统一设置：

```bash
export VIC_ENGINEERING_E43_ANALYTIC_BALL=1
export VIC_ENGINEERING_E43_PASSIVE_RAIL=1
```

两项目前仍为显式 opt-in。第一项仅对固定源 SHA 的14mm球采用解析球碰撞，保留视觉、半径、质量、原生 COM/惯量和材料。第二项为真实导轨增加被动粘性阻力：位置刚度0、目标速度0、阻尼1000、最大力0.08N，无位置锁止伺服；它是粘性近似，不是真静摩擦。两项必须在部署与评测间一致，不能运行中热改。

`VIC_ENGINEERING_E43_CONTACT_RESPONSE=1` **仅用于私有工程参考策略**，模型 serve 不需要，也不能借此调用 expert。该参考绑定 exact profile canonical SHA `7548e7dcc5a5418ee460b31736e54ad1e917e7168db9a99a4a41c1897f2542be`，不匹配会拒绝。对应文件为 `profiles/e43-reviewed-native5hz.json`；原15Hz文件为 `profiles/e43-reviewed.json`，配工程开关 `VIC_ENGINEERING_RENDER_HZ=5` 可得到同一5Hz配置。

## 运行

按根 README 配置 Isaac 与资产根，尤其真实斜坡 `source_plank_gravity_ramp_v2.usda` 及声明依赖。以下在交付的 `runtime` 中执行，使用全新输出目录；无模型/API：

```bash
VIC_ENGINEERING_E43_CONTACT_RESPONSE=1 \
python scripts/probe_realworld_room_pool.py \
  --bindings "$BINDINGS" --robot "$PROFILE_NATIVE5HZ" \
  --tasks E43 --variant B --seed 4201 \
  --execution-control positive --execution-action-budget 3000 \
  --execution-settle-ticks 600 --settle-ticks 240 --ticks 25 \
  --headless --device cpu --out "$NEW_OUTPUT"
```

`--experience` 与 `--kit_args --/physics/enableSceneQuerySupport=true` 按根 README 补齐。工程净空读取斜坡真正启用的 Cube 碰撞体8顶点，不能使用被禁用的视觉 Mesh 代替；板内接触点、等价导向面和另一转腕绕向均只改变合法动作路线，不改物理或评分。既有入口不重放，C 的未完成状态随包明示。
