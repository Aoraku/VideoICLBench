# E40：在指定图形处夹长尾夹

## 目标和规则

按照示范选择盘边图形，用长尾夹真实夹住相应位置。下表供维护者核验，不作为模型额外提示。

| 变体 | 需要夹住的图形 |
|---|---|
| A | 圆形、叉号 |
| B | 方形、三角形 |
| C | 圆形、三角形、叉号 |

## 操作与原生条件

夹子是原生弹簧关节机构，包含背脊和两个夹口，不能按刚性装饰块处理。实际挤压把手使夹口张开，将目标盘边放入两夹口之间，松开把手形成夹持并撤离。

原生记录要求有力驱动的张开过程、关节运动、释放后的回闭、两侧夹口与盘边接触及实际夹入几何。只记录末态双侧接触不足以证明完整张开/释放历史。额外图形不得误夹；以对应变体的原生条件为准。

已修复源87片碰撞几何在薄片烘焙中的坐标尺度问题；等价坐标表示保留源顶点和物理尺寸。工程入口用 `VIC_ENGINEERING_E40_COLLISION_COORDINATES=1` 及专用平滑夹爪配置，资产由HF包提供。接模型的独立服务默认不会运行工程参考；是否启用对应物理表示应保持与所选版本一致。
