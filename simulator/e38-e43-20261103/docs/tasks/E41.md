# E41：为不同长度木条接续一段

## 目标和规则

三个固定前段分别为短、中、长。根据示范的长度映射，选择可移动备件，在对应前段末端接续，前段不能移动。下表按短/中/长前段的顺序列出所需备件，属于维护者答案。

| 变体 | 短前段接 | 中前段接 | 长前段接 |
|---|---|---|---|
| A | 长备件 | 中备件 | 短备件 |
| B | 短备件 | 中备件 | 长备件 |
| C | 长备件 | 短备件 | 中备件 |

## 操作与原生条件

实际抓起三根备件，保持正确长度对应，旋转并运输到相应前段末端，放在台面支撑上后松手。原生同时检查映射、端点间隙、共线与方向、参照前段未动，以及真实释放、支撑和稳定。

源长度为72、100、138mm；原生端点间隙容许12mm、共线容许15mm，沿用原实现。不能把移动前段与备件一同拼到错误位置当作完成，也不能仅凭投影或长度总和判定。

本轮I条件/seed4201/Franka的ABC均已从源初态完整通过，所有原生条件有轨迹/末态证据。维护者文档规则不会被运行入口自动插入模型提示。
