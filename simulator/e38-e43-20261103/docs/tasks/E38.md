# E38：彩环按序套同一根柱

## 目标和规则

将红、绿、蓝三个真实环套到同一根指定立柱，按示范保持由下到上的颜色层序。下表是维护者规则，不作为模型额外提示。

| 变体 | 从下到上 |
|---|---|
| A | 红、绿、蓝 |
| B | 红、蓝、绿 |
| C | 蓝、绿、红 |

## 场景、操作与原生条件

场景包含带立柱的源工装板和三个有孔环。机器人需实际抓起环，使孔与立柱对齐，逐个套入，最后松手。验收检查实际柱/环几何、指定柱、层序、真实支撑与释放后的稳定状态；把环放在板边、仅让颜色中心重合或仍抓在手里都不等价于完成。

本轮I条件/seed4201/Franka的ABC均已有从源初态开始的完整原生正例，归入6条源初态证明，不需追加检查点拼接。
