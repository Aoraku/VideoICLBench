# 50 个具身任务的逐题实施卡

所有卡是设计规格，不是已实现任务。M=ManiSkill；R=RoboCasa/robosuite 路线。M+R 表示拟可跨后端，不表示两端已移植；先完成计划中的六桥接题。核心 30 题，进阶候选 20 题。每卡均继承主计划的通用状态/事件谓词、释放稳定、版本匿名、无文字规则和固定控制权限。这里的 A/B/C 说明仅供研究者，不能放入 Agent 输入。

**真实 demo 无字幕与语音解释；判分不使用 rubric。** “双臂可用”不等于强制双臂，“必须”类要验证物理或可见协议必要性。颜色 R/G/B 分别为红/绿/蓝；顺时针参考基垫局部朝向，所有初态生成必须检查三版可解且目标不同。

每题实际实现还要把自然语言规范编译成 `spec.yaml`、生成器和可运行 evaluator；当前 tasks.json 是任务卡清单，不是自动执行代码。容差、预算按先导冻结，不能把设计参数误称实测最优。

## B01 · 三色塔：底—中—顶

**积木结构 / 核心规格 / M+R / 双臂可用；不强制**

- **实物与起态**：红绿蓝各一块，边长约 40 mm；无答案的圆形基垫；其余留白。
- **A**：底→顶：红、绿、蓝。
- **B**：底→顶：绿、蓝、红。
- **C**：底→顶：蓝、红、绿。
- **真实 demo 与测试**：每版录 3 次完整搭建，起始左右位置不同；每放一层松手停顿；共 9 次放置。测试只搭 1 座三层塔。
- **仿真实现**：三块等尺寸刚体；基垫位置改变；全部颜色在两臂可达区域，不能由可达性决定层级。
- **自动判分**：三条 support 边（含基垫）与颜色层序正确；全部释放、无桌边支撑、稳定 1 s；无需匹配手部轨迹。
- **风险与不能省略的检查**：这题测层级顺序；不额外要求初次触碰顺序。不是强双臂任务，但必须保留作基本 ICL 校准。
- **参考**：[Ravens](https://github.com/google-research/ravens)、[VIMABench](https://github.com/vimalabs/VIMABench)、[RoboTwin](https://robotwin-platform.github.io/doc/tasks/)；[原创示意图](figures/01_stack_abc.svg)。

## B02 · 双塔配对

**积木结构 / 核心规格 / M / 双臂可并行**

- **实物与起态**：三色各 2 块；两个相同目标垫。
- **A**：两座塔都按红绿蓝自下而上。
- **B**：两座塔都按绿蓝红。
- **C**：两座塔都按蓝红绿。
- **真实 demo 与测试**：录 2 轮双塔；每轮先完成不同一侧，排除固定左右时序。测试 1 轮。
- **仿真实现**：两个垫的位置、六块起点变化；同色块可交换；不要求哪只手建哪座。
- **自动判分**：两张 support 子图都正确，六块各用一次；禁止靠两塔互相倚靠；松手稳定。
- **风险与不能省略的检查**：与 B01 共用结构族，不当作新的独立规则能力；增加多目标和并行调度。
- **参考**：[Ravens](https://github.com/google-research/ravens)、[RoboTwin](https://robotwin-platform.github.io/doc/tasks/)；[原创示意图](figures/04_structures.svg)。

## B03 · 两层错缝墙

**积木结构 / 核心规格 / M / 双臂可用**

- **A**：底层红绿蓝，上层蓝红绿。
- **B**：底层绿蓝红，上层红绿蓝。

- **仿真实现**：所有版本几何相同；偏移量控制在经验证的静态稳定范围，颜色只改变位置。
- **自动判分**：颜色到六个相对槽位匹配、接触支撑关系正确、上层偏移正确；整体释放稳定。

## B08 · 多座两层塔的完成顺序

**积木结构 / 核心规格 / M / 双臂可并行但有顺序**

- **实物与起态**：三色各 2 块；三个分别有颜色点的基垫。
- **A**：完成红塔→绿塔→蓝塔。
- **B**：完成绿塔→蓝塔→红塔。

- **自动判分**：终态三座同色塔正确；首次完成事件全序符合。之后拆毁重做不抹去历史。
- **风险与不能省略的检查**：这是明确的过程题；统一协议要求复现关键完成顺序，不能临时在 judge 加要求。

- **参考**：[robosuite](https://robosuite.ai/docs/modules/environments.html)、[RoboCasa](https://robocasa.ai/)；[原创示意图](figures/07_bimanual.svg)。

## B48 · 抽屉—旋钮—按钮顺序

**工具与接触 / 核心规格 / R+M / 双臂可用**

- **实物与起态**：桌面机械面板，抽屉、三档旋钮、大按钮，初态一致。
- **A**：拉开抽屉→旋钮转中档→按按钮。
- **B**：旋钮中档→按按钮→拉开抽屉。
- **C**：按按钮→拉开抽屉→旋钮中档。
- **真实 demo 与测试**：3 次完整流程，终态相同；动作后停顿展示状态；测试面板位置变化。
- **仿真实现**：所有顺序都物理可行，面板不以规则解锁动作；不做问答提示。
- **自动判分**：首次有效开抽屉、进入中档、按钮触发事件全序与终态正确。
- **风险与不能省略的检查**：按钮反弹计一次需去抖；不能用控制器调用顺序替代实际状态变化。
- **参考**：[RLBench](https://github.com/stepjam/RLBench)、[CALVIN](https://github.com/mees/calvin)、[RoboCasa](https://robocasa.ai/)；[原创示意图](figures/07_bimanual.svg)。

## B49 · 持板插入并锁定夹座

**工具与接触 / 进阶候选 / M / 持件+操作锁：必须**

- **实物与起态**：三个同功能带符号夹座与一块宽柄板；操作为插板并合上夹锁。
- **A**：装入圆夹座并锁定。
- **B**：装入三角夹座并锁定。
- **C**：装入方夹座并锁定。
- **真实 demo 与测试**：3 次，另一手持板直至夹锁闭合，然后松开；目标夹座位置变化。
- **仿真实现**：使用可动夹爪关节模拟夹锁；三座同样适配；未锁时板不稳定。
- **自动判分**：目标座内板深度、夹锁角度、持板至锁定事件、松手稳定都满足。
- **风险与不能省略的检查**：力学不能靠目标规则决定吸附；如果保持必要性不足，只标协作协议题。

## B50 · 完整工作单元：取件—装配—收纳

**过程与组合 / 核心规格 / M+R / 交接与协作**

- **实物与起态**：三个同形符号料盒、每盒一套红绿蓝积木；施工垫、工具托盘、两根宽柄辅助杆（初态放在施工区边缘）。
- **A**：从圆盒取件，红绿蓝底到顶，剩余盒保持关闭。
- **B**：从三角盒取件，绿蓝红底到顶。
- **C**：从方盒取件，蓝红绿底到顶。
- **真实 demo 与测试**：每版 2 次完整取料/搭建/整理；完成塔留施工垫，托盘收纳工具，避免搬脆弱整塔。
- **仿真实现**：三个盒同等可达；料色齐全；不让唯一开盒或缺料泄漏版本。
- **自动判分**：正确料源、正确塔、使用料盒关上、工具归盘；完整事件证据；其他盒终态保持。
- **风险与不能省略的检查**：组合题复用 B01/B21，不计作独立新规则族；长程难度独立报告。
