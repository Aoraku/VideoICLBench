# VIC-Chat

VIC-Chat is a full-stack instant messaging project organized as a monorepo.

## Structure

- `backend/`: Django backend service and API documentation.
- `frontend/`: React/Vite frontend project.

## Source Snapshot

- Backend source commit: `c94dc3b`
- Frontend source commit: `b389ae8`

## Notes

Runtime secrets such as `.env` files, API keys, local databases, dependency
directories, and build outputs are intentionally excluded from this repository.
